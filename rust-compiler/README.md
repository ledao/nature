# Nature Compiler - Rust Implementation

这是Nature编程语言编译器的Rust实现，使用LLVM进行代码生成。

## 🎯 项目目标

- ✅ **100%兼容Nature语法**：完全支持现有Nature语言的所有语法特性
- ✅ **使用LLVM代码生成**：利用LLVM的强大优化和跨平台支持
- ✅ **在现有项目中追加**：不破坏原有C实现，并行开发
- ✅ **完善的单元测试**：确保代码质量和兼容性

## 🏗️ 项目结构

```
rust-compiler/
├── Cargo.toml              # Rust项目配置
├── src/
│   ├── main.rs             # CLI入口
│   ├── lib.rs              # 库入口
│   ├── error.rs            # 错误处理
│   ├── lexer/              # 词法分析
│   │   ├── mod.rs
│   │   └── token.rs
│   ├── parser/             # 语法分析
│   │   ├── mod.rs
│   │   ├── expr_parser.rs
│   │   ├── stmt_parser.rs
│   │   ├── decl_parser.rs
│   │   └── type_parser.rs
│   ├── ast/                # AST定义
│   │   ├── mod.rs
│   │   ├── expr.rs
│   │   ├── stmt.rs
│   │   ├── decl.rs
│   │   └── types.rs
│   ├── semantic/           # 语义分析

│   │   └── symbol_table.rs

│   └── utils/              # 工具函数

└── examples/               # 示例
```

## 🛠️ 技术栈

- **语言**: Rust (内存安全、高性能)
- **解析**: Logos (高性能词法分析) + 手写递归下降解析器
- **代码生成**: LLVM (强大的优化和跨平台支持)
- **测试**: Criterion (性能测试) + 自定义测试框架
- **构建**: Cargo (Rust标准构建工具)

## 🚀 快速开始

### 构建项目

```bash
cd rust-compiler
cargo build
```

### 运行测试

```bash
cargo test
```

### 运行示例

```bash
cargo run -- build examples/hello.n
```
